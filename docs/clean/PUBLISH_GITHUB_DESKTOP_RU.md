# Публикация исходников через GitHub Desktop

Используйте новую папку DeepSeek-Harness-CleanFix-Source. У неё самостоятельная история без прежних бинарных архивов. Точный SHA проверенного коммита передаётся в локальной памятке; в History GitHub Desktop сверяйте полный SHA.

1. File → Add Local Repository → выберите новую папку. Проверьте main и No local changes.
2. Самостоятельно Publish repository под **новым свободным именем** и снимите Keep this code private. На этапе подготовки remote отсутствует, push не выполняется.
3. Сдавайте URL конкретного коммита /commit/FULL_SHA. Ссылка на main не фиксирует проверенную версию.

Уже опубликованный прежний репозиторий всё ещё содержит архивы в старых коммитах. Удаление payload следующим коммитом не удаляет их из истории. Самый простой путь без переписывания опубликованной истории — новый репозиторий исходников. Если нужно сохранить прежний URL, замена его истории должна быть отдельным осознанным действием владельца; подготовка её автоматически не выполняет.

После скачивания исходников зависимости устанавливаются по инструкции. Не добавляйте node_modules, pnpm store, готовые бинарники, модели, VM, пароли, сессии и сырые логи. Проверка — deploy/Verify-Publication.py; значения проверяемых секретов хранятся вне репозитория. Шаблонный скан не доказывает отсутствие любого мыслимого секрета.
